# Конструктор поручений

Прототип сервиса для партнёров кадровой платформы «Уполномоченный на результат» (ФДОС при Уполномоченном при Президенте РФ по правам ребёнка).

Компания выбирает сферу и цель, собирает формулировку задачи из готовых вариантов — конструктор разбивает её на поручения для подростков 14–15, 16–18 и 19–20 лет, проверяет текст на риски по закону и готовит поручения к модерации.

Разделы: главная, конструктор для компаний, витрина поручений для подростков, раздел для родителей, правила модерации и закон, конфиденциальность.

Сайт — один статический файл `index.html` без внешних зависимостей: шрифты и библиотека QR-кода встроены, данные не собираются и не отправляются.

Подготовлен студентами РАНХиГС в рамках социальной задачи ФДОС № 4442 «Разработка стратегии по привлечению партнёров», 2026.
